# STAligner correctness migration

Different Visium slices often share barcodes. Supply batch identities explicitly:

```python
model = ov.space.pySTAligner(
    combined, batch_key='slice',
    Batch_list={'slice_a': slice_a, 'slice_b': slice_b},
    n_epochs=1000, pretrain_epochs=500, device='cpu',
)
model.train()
result = model.predicted()
```

Combined observations must be contiguous in batch order, and each block must
match the corresponding source observations (uniform concatenation suffixes
are supported). A list with shared names requires batch_ids or constant batch
labels in the individual objects. Unidentifiable positional adjacency requires
rerunning Cal_Spatial_Net. Named edges are realigned to current observation order.

Both training stages use the per-batch expression matrices, restricted to the
combined gene order. Do not expect combined.X to select a different training
scale. Default short runs reserve half their epochs for MNN alignment; every
requested batch pair must yield usable anchors and the pair graph must connect
all batches. At least two observations per batch are required. Predictions
before successful training are errors.

Optional hnswlib uses approximate MNN. Without it, exact sklearn MNN is used
with a warning; mnn_approx=False selects exact search explicitly. Tensor graph
inputs do not require torch-sparse. Recompute embeddings generated by the old
row-order, graph-offset or pretraining-only behavior.

Local validation: 16 focused tests passed, including real two-stage training,
shared barcodes, expression-source consistency, named-edge realignment,
deterministic initialization, duplicate coordinates and empty MNN rejection.
No CI, setup.py or dependency configuration was changed.
